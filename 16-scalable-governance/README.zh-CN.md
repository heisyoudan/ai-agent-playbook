# 16 — 规模化治理与决策压缩

[日本語](README.ja.md) · [English](README.md) · **简体中文**

**状态：草稿（章节框架）。** 成熟度：**Working Hypothesis（工作假设）** —— 规模化问题已被观察到，但所提出的机制尚未验证。跟踪记录在[研究孵化器](../research/README.zh-CN.md)中。

## 本章要回答的问题

治理如何随项目一起扩展，而不成为瓶颈？

## 为什么需要这一章

依赖人工审查每一个决策的治理无法扩展，而且会悄悄退化：审查者开始按模式批准，审查不再是真正的控制。

**决策压缩（Decision Compression）** 指的是，把重复出现的判断一次性编码为规则、默认值、模板或检查清单，从而不必每次重新论证，同时保留可回溯的判断依据。这与工程团队使用标准和规范的方式相似，但要有意识地应用于 Agent 产出的工作。

风险很明显，而且它本身就是假设的一部分：一个从未被重新审视的压缩决策，会变成未经审查的规则；而没有人记得理由的规则，很难被正确修正。

## 预计纳入的概念

- 作为压缩候选的重复决策
- 作为压缩决策的规则、默认值、模板与检查清单
- 带有明确适用范围的先例授权
- 记录判断依据，使压缩结果可被修订
- 需要重新打开某个压缩决策的触发条件
- 单次变更的治理成本，以及它随项目增长的变化

## 当前成熟度

工作假设。与第 12 章（决策权、人类质量门与决策压缩）和第 06 章（把工作流当作产品）相关。机制已在实践中应用，但尚未被度量。
