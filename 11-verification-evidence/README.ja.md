# 11 — 検証と証拠

**日本語** · [English](README.md) · [简体中文](README.zh-CN.md)

**状態：ドラフト（章の骨格）。** 成熟度：**Derived Principle（導出された原則）** — 実務の検証作業から導かれたが、一部の仕組みは検証中である。継続的な証拠は[リサーチ・インキュベーター](../research/README.ja.md)で追跡する。

[付録B](../appendix/verification-strategies.ja.md)は具体的な検収戦略を列挙している。この章はその一段下にある設計上の問いを扱う。

## この章が扱う問い

ある主張を受け入れる前に、何が成立していなければならないか。

## なぜこの章が必要か

「完了しました」は証拠ではない。説得力のある説明も証拠ではない。価値の大半は次の二つの区別にある。

- 実行**前**に設計された検証は制御である。実行**後**に作られた検証は点検である。
- 他者が再確認できる証拠は証拠である。物語としてしか存在しないものは証言である。

第02章はすでに検収基準を要求している。この章は、その基準が何を生み出すべきか、誰が再現できるか、いつまで有効かを問う。

## この章に属すると想定される概念

- 証拠の種類：テスト出力、実行時の挙動、計測値、一次資料
- 実行前に設計し、主張の種類に適合させた検証
- 独立した再現と自己申告の区別
- 確証より反証：何が示せればこの主張は誤りと言えるか
- どの証拠を、いつまで、誰のために保持するか
- 検証の費用と、漏出した不具合の費用
- 証拠を真実へ膨らませずに、複数セッションで再利用すること

## 現在の成熟度

長期の実践に基づくが、証拠の分類と保持規則は形成途上である。
