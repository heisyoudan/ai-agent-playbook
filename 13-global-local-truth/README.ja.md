# 13 — グローバル真実・ローカル真実と真実投影

**日本語** · [English](README.md) · [简体中文](README.zh-CN.md)

**状態：ドラフト（章の骨格）。** 成熟度：**Working Hypothesis（作業仮説）** — もっともらしいモデルだが、方法論として扱うには証拠が足りない。追跡は[リサーチ・インキュベーター](../research/README.ja.md)で行う。

## この章が扱う問い

プロジェクトが、どの単一の Agent も推論しきれない量の真実を抱えるとき、ひとつのサブシステムは実際に何を知る必要があるのか。

## なぜこの章が必要か

すべての Agent にプロジェクト全体の真実を渡すことはできない。かといって雑な要約は、何も渡さないより悪い。もっともらしい部分的な見え方は、完全な見え方と区別がつかないからである。

**投影（Projection）** とは、ある範囲が受け取るグローバル真実の部分集合を、どのような条件で受け取るかを意図的に決める行為である。着想は魅力的で、部分的に観察もされている。ただし強い前提を伴う。グローバル真実が投影できる程度に整備されていること、投影を最新に保てること、そして投影からのローカルな推論が全体と静かに矛盾しないこと。この前提こそが未解決の問いである。

## この章に属すると想定される概念

- グローバル真実とローカル真実を、所有者の異なる別物として扱うこと
- 所有者を持つ設計された見え方としての投影（フィルタ済みコピーではない）
- 一貫性の保証と、それが成立しない範囲を正直に示すこと
- 陳腐化ウィンドウ：投影が誤解を生むまでに許される遅れ
- ローカル真実がグローバル真実と衝突する場合
- 投影の契約と無効化のトリガー

## 現在の成熟度

作業仮説である。第08章（真実のガバナンス）と第09章（有効な推論範囲）に関連するが、仕組みは規模を伴って検証されていない。反例を積極的に探している段階である。
