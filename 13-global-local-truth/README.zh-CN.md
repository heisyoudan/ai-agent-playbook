# 13 — 全局真相、局部真相与真相投影

[日本語](README.ja.md) · [English](README.md) · **简体中文**

**状态：草稿（章节框架）。** 成熟度：**Working Hypothesis（工作假设）** —— 一个说得通的模型，但证据尚不足以当作方法论使用。跟踪记录在[研究孵化器](../research/README.zh-CN.md)中。

## 本章要回答的问题

当项目持有的真相超出任何单个 Agent 能推理的规模时，某一个子系统实际需要知道什么？

## 为什么需要这一章

不可能把项目全部真相交给每个 Agent。而草率的摘要比什么都不给更糟——因为看起来合理的局部视图与完整视图难以区分。

**投影（Projection）** 是有意识地决定某个范围接收全局真相的哪个子集、以及按什么条件接收。这个想法有吸引力，也已被部分观察到。但它带有很强的前提：全局真相本身维护得足够好、投影能被保持为最新、以及基于投影的局部推理不会静默地与整体矛盾。这些前提正是当前的未解问题。

## 预计纳入的概念

- 把全局真相与局部真相当作归属不同的两样东西
- 投影是有归属者、被设计出来的视图，而不是过滤后的副本
- 一致性保证，以及诚实说明它在哪些范围不成立
- 陈旧窗口：投影在多长时间内落后仍不至于误导
- 局部真相与全局真相冲突时会发生什么
- 投影契约与失效触发条件

## 当前成熟度

工作假设。与第 08 章（真相治理）、第 09 章（有效推理范围）相关，但机制尚未在规模化场景下验证；当前正在主动寻找反例。
